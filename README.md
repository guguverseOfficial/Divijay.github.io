# 🐱 DIVIJAY ENGINE

> **"They made Undertale on GameMaker, and I'm making the Divijay Engine. No need to doubt this engine!"**

Welcome to **Divijay Engine** — the most meme, lightest and craziest rhythm game engine (inspired by Friday Night Funkin'). 

I created this engine to prove that a cool game doesn't need gigabytes of garbage. There are no tons of unnecessary scripts, heavy video libraries, or boring standard characters. Just you, the music, the arrows, and the ** Cat with glasses**.

---

## 🚀 Why Divijay Engine?

* ** Ultra-light weight**: Forget about 500 MB engines. Divijay Engine weighs pennies and flies even on weak laptops.
* ** Meme vibe**: Easter eggs, secrets and a Cat who is not drunk, he is like that.
*   **🛠️ Full support for mods**: You can create your own songs by simply uploading JSON files and music to the mods folder.
* **⚡ Made on GameMaker**: The same engine used to make Undertale.

---

## 📦 How to play?

1. Download the latest Divijay Engine release ('.exe` file).
2. Start the game.
3. Press **Enter** (or click on the button) to start.
4. If you have a mods folder with songs, the engine will pick them up automatically!

---

## 🛠️ How to create your own mod (Mod Template)

Creating mods for Divijay Engine is easy. You don't need to be a programmer.

1. Create a `mods' folder next to `Divijay Engine.exe ` (if it doesn't exist).
2. Create a folder for your mod inside (for example, `MyAwesomeMod').
3. Create the following structure inside the mod folder:

```text
MyAwesomeMod/
├── mod_info.json (Fashion Information)
├── charts/
│   └── song1.json (Your chart with sheet music)
├── audio/
│ └── Inst.ogg (Music)
└── images/
    └── background.png (Background for the song)
